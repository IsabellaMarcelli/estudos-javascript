# Estudos de JavaScript

Projetos que desenvolvi enquanto estudava JavaScript nos cursos da [Alura](https://www.alura.com.br). O layout e o código inicial de cada projeto vêm dos cursos. A lógica em JavaScript eu escrevi acompanhando as aulas, com comentários próprios explicando cada parte.

## Projetos

| # | Projeto | O que pratiquei | Como rodar |
|---|---------|-----------------|------------|
| 01 | [Alura MIDI](./01-alura-midi) | Manipulação do DOM, eventos de clique e teclado, laços `for`, áudio no navegador | Abrir `index.html` no navegador |
| 02 | [CodeConnect](./02-codeconnect-promises) | Promises, `async/await`, `try/catch`, `FileReader`, `setTimeout` para simular requisições | Abrir `index.html` no navegador |
| 03 | [Fundamentos de JavaScript](./03-fundamentos-javascript) | Variáveis, tipos, operadores, arrays, condicionais e loops | `node 1-meuPrimeiroPrograma.js` (e assim por diante) |
| 04 | [Jogo do número secreto](./04-jogo-numero-secreto) | Lógica de programação, `while`, `prompt`/`alert`, operador ternário | Abrir `index.html` no navegador |
| 05 | [Página Alura Plus](./05-pagina-alura-plus) | Estrutura HTML e estilização com CSS | Abrir `index.html` no navegador |

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js (para os exercícios de fundamentos)
